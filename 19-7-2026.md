## 2. Điểm hạn chế phát hiện & Đề xuất Tối ưu (Lỗi Chấm công ca đêm)
- **Vấn đề:** 
  - Hàm `checkOut` hiện tại vẫn sử dụng điều kiện `work_date = today` dẫn đến việc nhân viên đi ca đêm (check-in tối hôm trước, check-out sáng hôm sau) bị báo lỗi không tìm thấy lượt check-in hôm nay.
- **Giải pháp tối ưu đã thống nhất:**
  - Bỏ điều kiện cứng lọc theo ngày dương lịch `work_date = today`.
  - Thay thế bằng điều kiện lọc động `check_in >= DATE_SUB(NOW(), INTERVAL 24 HOUR)` để chỉ lấy lượt check-in chưa check-out trong vòng 24 giờ qua.
  - Vừa hỗ trợ ca đêm hoàn hảo, vừa tự động loại bỏ các lượt quên check-out (bản ghi treo) của những ngày trước.

## 3. Nội dung Code đề xuất thay đổi (attendance.controller.js)

### Đoạn code cũ:
```javascript
const { today } = getVietnamTime()
const [existing] = await pool.execute(
  "SELECT id, check_in FROM attendances WHERE employee_id = ? AND work_date = ? AND check_in IS NOT NULL AND check_out IS NULL ORDER BY check_in DESC LIMIT 1",
  [employee.id, today]
)
if (existing.length === 0) return res.status(400).json({ message: "Bạn chưa check-in hôm nay, không thể check-out" })
```

### Đoạn code mới:
```javascript
const [existing] = await pool.execute(
  "SELECT id, check_in FROM attendances WHERE employee_id = ? AND check_in IS NOT NULL AND check_out IS NULL AND check_in >= DATE_SUB(NOW(), INTERVAL 24 HOUR) ORDER BY check_in DESC LIMIT 1",
  [employee.id]
)
if (existing.length === 0) return res.status(400).json({ message: "Không tìm thấy bản ghi check-in hợp lệ để check-out" })
```

## 4. Các rủi ro tiềm ẩn khác (Chờ xử lý sau)
1. **Lỗ hổng GPS Spoofing:** API check-in nhận trực tiếp `latitude` / `longitude` từ request body của client mà không qua xác thực mã hóa của thiết bị quét cố định.
2. **Đăng nhập thiết bị lạ lần đầu:** Kẻ xấu có thể đăng nhập trước trên thiết bị của họ khi tài khoản mới được tạo để chiếm khóa thiết bị (Device Lock).
3. **Thiếu Transaction:** Khi tạo nhân viên mới hoặc import Excel, nếu ghi bảng `employees` thành công nhưng bảng `users` lỗi sẽ gây tình trạng mồ côi dữ liệu.
